# Jenesis CDC

A nonprofit website for Jenesis CDC, featuring programs, coalition information, event sponsorship, contact forms, and a custom site assistant.

🔗 **Live site:** [jenesis-cdc.lovable.app](https://jenesis-cdc.lovable.app/)

## About

This site serves as the digital home for Jenesis CDC, giving visitors an easy way to learn about the organization's programs, explore coalition partnerships, view event sponsorship opportunities, and get in touch through built-in contact forms. It also includes a custom AI-powered site assistant to help visitors quickly find information.

## Features

- **Programs overview** — details on Jenesis CDC's community programs
- **Coalition information** — partner organizations and initiatives
- **Event sponsorship** — info and calls to action for sponsors
- **Contact forms** — direct way for visitors to reach the org
- **Custom site assistant** — AI-powered chat to help users navigate the site

## Tech Stack

- **TypeScript** — primary language
- **CSS** — styling
- **JavaScript**
- Built on the TanStack Start template

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/uzair-nasir/jenesis-cdc.git
cd jenesis-cdc
bun install
```

Run the dev server:

```bash
bun run dev
```
